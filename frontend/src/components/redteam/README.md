# Red Team Lab (frontend)

**Defensive testing tool — not an attack toolkit.**

This UI drives `ml-engine` perturbations against *existing* live or replayed audio so the
team can show acoustic family scores degrading under evasion while contextual families hold
(Context §9.3 / §16.2).

It does **not** generate, improve, or synthesize voice clones (no RVC, TTS, or speaker
embedding transfer). See also `ml-engine/README.md` and `GET /engine/redteam/capabilities`.
