# F11 — Streaming ASR + tenant-aware intent (Stage A / Stage B)

## Decision

Rewrite the ml-engine slow path for V2 privacy and latency:

| Stage | Role | Latency budget |
|-------|------|----------------|
| **ASR** | faster-whisper on VAD-gated PCM windows; rolling transcript **in RAM only** (~20 s), zeroised on session close | Slow path (~2.5 s cadence) |
| **Stage A** | Deterministic tenant lexicon + generic fallback + entity rules | **&lt; 50 ms** (sync, every segment) |
| **Stage B** | Async `runtime_intent` via local LLM gateway | **≤ 2500 ms**; never blocks Stage A / 500 ms emit |

Transcript text is **never** logged, persisted, or placed on a FeatureFrame. A runtime privacy guard strips/rejects `redactedSnippet` / `redactedDelta` / raw `claimedIdentity` on the wire.

## Schema

`docs/contracts/v2/FeatureFrame.schema.json` — `LinguisticFamily` gains:

- `source`: `STAGE_A` \| `STAGE_B` \| `MERGED`
- `observedAt`, `confidence`, `categories`, `matchedRuleIds`, `injectionAttempt`, `llmPending`
- `Ask` optional `sharesCredential` / `beneficiaryMentioned`; amount/currency nullable

Regenerate: `bash scripts/gen-contracts.sh` then `bash scripts/validate-contracts.sh`.

## ml-engine

| Module | Role |
|--------|------|
| `modules/privacy.py` | PII redactor for LLM input, injection detect, wire guard |
| `modules/stage_a.py` | Fast lexicon + amount/credential/directory fuzzy |
| `modules/stage_b.py` | Rate-limited async LLM (1 / 3 s, coalesce), stats |
| `modules/tenant_lexicon.py` | Fetch/cache `/internal/v2/linguistics/lexicon` |
| `slow_path.py` | ASR → Stage A → schedule Stage B on silence / high risk |
| `routes/f11_sessions.py` | `gate-wait`, linguistic-stats |

## Java

| Piece | Role |
|-------|------|
| `InternalLinguisticsController` | Service-token lexicon bootstrap |
| `GateCheckController` | `POST /internal/v2/sessions/{id}/gate-check` (≤800 ms wait) |
| `FactAssembler` | Maps extraction → `ask.*` with source/confidence/`assertedByCaller`; `caller.promptInjectionAttempt` |
| `FeatureFrameIngestService` | Applies `missingEvidence.llmUnavailable` (`CONTINUE_RULES_ONLY` \| `RAISE_ONE_LEVEL`) |
| Live Calls API | `linguisticStatus` / age / source on active rows |
| Settings | `asrLanguages` in tenant `extras` |

## Frontend

| Surface | Role |
|---------|------|
| Live Calls | **Linguistic** column: live / pending / unavailable (+ age) |
| Settings → ASR languages | Editable language list + honest accuracy note |

## Privacy / threat notes

1. Stage B input is PII-redacted and wrapped in `<untrusted_data>`.
2. Instruction-like phrases → `injectionAttempt=true` and **increases** suspicion (`caller.promptInjectionAttempt`).
3. On Stage B timeout: Stage A-only snapshot continues; fusion may raise one level if configured.

## Lab acceptance

1. Place a call with payment/urgency language → Live Calls shows linguistic **live** or **pending**, then **live**.
2. Confirm FeatureFrame ingest logs never contain transcript text.
3. Operator Approve path: `POST /internal/v2/sessions/{svSessionUuid}/gate-check` with service token returns freshest level after ≤800 ms wait.
4. Settings languages save round-trips; lexicon endpoint returns keywords for ACTIVE policy set.
