# F4 — Tenant directory

## What was built

- Flyway `V005__directory.sql`: departments, employees, phones, authority, external parties,
  beneficiary accounts (HMAC only), known_relationships, directory_imports — all FORCE RLS.
- `fn_revert_expired_employee_status()` SECURITY DEFINER for scheduled status expiry.
- CRUD REST under `/api/v2/directory/**` (TENANT_ADMIN write; ANALYST/AUDITOR read).
- CSV/XLSX import dry-run → confirm commit; downloadable templates.
- `DirectoryService.resolve` → `DirectoryMatch` (NUMBER_EXACT | EXT_EXACT | NAME_FUZZY | NONE).
- `RelationshipService.query` / `recordContact` (F10 hook surface).
- Phone E.164 via libphonenumber; fuzzy name Jaccard threshold from `tenant_settings.extras.directory.nameFuzzyMin` (default 0.72).
- Frontend `/app/directory` tabs: Employees (drawer), Departments + org chart, Externals, Beneficiaries, Import wizard.
- v1 `TrunkClassifier` and stub `identity.DirectoryService` removed. `IdentityAssessment` adapter marked **REMOVE IN F7**.
