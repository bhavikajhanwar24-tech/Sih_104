# F12 — Per-call explainability + forensic dossier

## Decision

Persist sampled risk ticks and typed reason codes under tenant RLS (no call media,
no speech text). Assemble court-ready forensic dossiers from Decision Plane retained
state only; stamp PDF digests into the audit chain.

| Source | Role |
|--------|------|
| `session_ticks` | Sampled score/level/family_scores timeline |
| `session_reasons` | Template-backed reason codes + contributions |
| `session_extractions` | Ask/category **enums** only |
| `session_actions` | Response-plan actuation log (F9) |
| `forensic_dossiers` | Content + PDF digests + audit seq range |
| `audit_blocks` | Hash-chained seal (`DOSSIER_GENERATED`) |

## Prerequisites (lab)

| Feature | Status | Evidence |
|---------|--------|----------|
| **F10** real calls → `call_sessions` | Required | Softphone lab writes rows; Live Calls / Call History list them |
| **F9** response plans | Required for action markers | `GET /api/v2/response/plans/active` |
| **F11** runtime LLM / Stage A–B | Required for linguistic ticks/enums | ml-engine `stage_a`/`stage_b`; FeatureFrame ingest |

Softphone ConfBridge without media→ML FeatureFrames will create `call_sessions` but
**zero** `session_ticks` / `session_reasons`. That is expected until the AudioSocket /
ingest path runs for the session.

## Schema

`V021__explainability.sql` — tables above + `tenant_settings.explain_*` sampling knobs
+ `call_sessions.review_status` / `reviewed_at` / `reviewed_by` for analyst disposition.

## Java

| Piece | Role |
|-------|------|
| `SessionExplainRecorder` | Hot-path sample write on FeatureFrame ingest |
| `ReasonCode` / `ReasonTemplates` / `reasons*.properties` | Typed codes + EN/HI text |
| `ReasonGenerator` | Template expansion only — never LLM text as decision |
| `ForensicDossierService` | Assemble from DB; OpenPDF via `DossierPdfRenderer`; window-exclusion SHA |
| `SessionsController` | `/api/v2/sessions` list/detail/ticks/review/dossier (`?lang=en\|hi`) |
| `AuditVerifyController` | `GET /api/v2/audit/verify-dossier?hash=` |

Removed: `/api/v1/forensics` (`ForensicReportController`).

## API

| Method | Path | Auth |
|--------|------|------|
| GET | `/api/v2/sessions?from&to&minLevel&employeeId&outcome&reviewed&limit&offset` | TENANT_ADMIN / ANALYST / AUDITOR |
| GET | `/api/v2/sessions/{id}?lang=en\|hi` | same — explain payload; titles localized via resource bundle |
| GET | `/api/v2/sessions/{id}/ticks` | same |
| POST | `/api/v2/sessions/{id}/review` | TENANT_ADMIN / ANALYST — body `{ "status": "FALSE_POSITIVE" \| "CONFIRMED_FRAUD" \| "UNREVIEWED" }` |
| GET | `/api/v2/sessions/{id}/dossier` | same — JSON (`ForensicDossier/2`) |
| GET | `/api/v2/sessions/{id}/dossier.pdf` | same — PDF + `X-Document-SHA256` |
| GET | `/api/v2/audit/verify-dossier?hash=` | same — lookup by `content_sha256` (tenant-scoped) |

`{id}` resolves as `call_sessions.id` **or** `sv_session_uuid`.

## Frontend

| Surface | Role |
|---------|------|
| `/app/history` | Call History filters (date, min level, employee, outcome, reviewed) |
| `/app/sessions/:id` | Detail: timeline + markers, Why (lang toggle), actions, PDF, **Mark FP / Confirmed** review |
| `/app/policies?tab=documents&doc=&clause=` | Deep-link from Why citation |
| Live Calls rows | Link to `/app/sessions/:id` |

Review dispositions write `call_sessions.review_status` + `SESSION_REVIEWED` audit. History
`reviewed` filter uses the same column.

Softphone Force L3 / analyst override also records an operator tick + reason so Call Detail
is not empty when FeatureFrames are absent (ConfBridge without AudioSocket).

## Privacy

1. No PCM/WAV/media bytes or speech text in DB, dossier JSON, or PDF body copy
   (privacy statement must not name media formats as if they were present).
2. Amounts stored as ranges (`<10k`, `10k-100k`, …) only.
3. Dossier PDF footer seal uses window-exclusion SHA so printed digest matches file bytes.

## SQL checks

Run `scripts/verify_f12.sql` (read-only) with `:tenant_id` set to the tenant UUID.

## Manual verification script

Prerequisites: Flyway through V021, backend + frontend + Asterisk up, `SIP_EXTERNAL_IP`
set, tenant ANALYST (or TENANT_ADMIN), Zoiper accounts registered (F10). Prefer a call
that also drives FeatureFrames (ML media path) so ticks/reasons populate.

1. **History** — Open `/app/history`. Confirm rows from `GET /api/v2/sessions` with names,
   peak level, duration, newest first. Apply **From/To**, **Min level**, **Employee**,
   **Outcome** filters; list shrinks accordingly.
2. **Detail** — Click a row → `/app/sessions/{id}`. Confirm:
   - Risk timeline (or honest empty note if no ticks).
   - Why panel with `code`, contribution, citations when present.
   - Language toggle **हिन्दी** changes reason **titles** (bundle), dates/numbers stay numeric/local.
   - Actions section shows F9 steps or an explicit “not tracked” note.
   - Extractions section shows enums or an explicit F11-unavailable note.
3. **Clause deep-link** — If a reason has `sourceClause.documentId`, click
   **Open cited policy document** → Policies Documents modal opens and scrolls/highlights
   the matching chunk.
4. **Dossier JSON** — `GET /api/v2/sessions/{id}/dossier` returns
   `schema: sentinelvoice.ForensicDossier/2`, `tenantId`, privacy statement without
   claiming stored media.
5. **Dossier PDF** — Download from Call Detail. Header `X-Document-SHA256` is 64 hex;
   footer contains `SVSHA256=` + digest. Extract text: no phone/account numbers; no
   speech content; privacy statement only.
6. **Verify** — Copy `manifestSha256` / `contentSha256` from dossier JSON →
   `GET /api/v2/audit/verify-dossier?hash=…` → `valid: true`. Flip one hex digit →
   `valid: false`. Log in as another tenant → same hash → `valid: false` / not found.
7. **Live link** — From `/app/calls`, open a session detail URL after hangup; status is
   **Ended** (not stuck Live).
8. **Review** — On Call Detail, **Mark FP** → badge `FALSE_POSITIVE`; History filter
   **Reviewed** shows the row. **Confirmed** → `CONFIRMED_FRAUD`. **Clear review** resets.
9. **Softphone tick** — From Live Calls, **Force L3 (lab)** on an active call → open session
   detail → Risk timeline / Why show at least one operator tick/reason (not empty).
