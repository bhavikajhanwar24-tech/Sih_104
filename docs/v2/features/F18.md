# F18 — Demo seeding & scenario lab

## Decision

Demo tenants are seeded through real services (not `data.sql`). Scenario
fixtures are JSON under `classpath:/scenarios/`; the lab runs **real WAV
audio** into ml-engine (and optional ARI originate). Fake FeatureFrame
injection into live sessions is removed.

## Schema

`V030__f18_demo.sql` — `tenants.is_demo` for reset scoping.

## Seed / reset (dev|demo|lab only)

| Method | Path | Auth |
|--------|------|------|
| POST | `/internal/v2/demo/seed?tenant=demo-bank` | ML_SERVICE internal |

## Manual verification (fresh DB)

### Prerequisites

1. Backend + frontend + ml-engine up; Flyway through **V031**.
2. `.env`: `LAB_MODE=true`, non-prod profile (`demo`/`dev`), `ML_SERVICE_TOKEN` set.
3. Restart Decision Plane after changing `LAB_MODE`.

### Script

1. **Seed**
   ```bash
   curl -s -X POST "http://localhost:8081/internal/v2/demo/seed?tenant=all" \
     -H "X-ML-Service-Token: $ML_SERVICE_TOKEN"
   ```
   Console prints `DemoPassw0rd!` and emails `admin@demo-bank.demo` / `admin@demo-insurer.demo`.

2. **Login** `admin@demo-bank.demo` / `DemoPassw0rd!`

3. **Directory / Policies / Response** — ~25 employees with phones+authority; ACTIVE policy set (DEMO_FIXTURE); ACTIVE response plan L1–L4.

4. **Dashboard → Configuration health** — all five checklist rows green (policy, response plan, directory, phones, authority).

5. **Lab** (`LAB_MODE=true`) → select **Deepfake CFO wire** (scenario 2) → **Run**. Watch **Live Calls** climb toward L3/L4; action panel fires tenant plan. Open **Call Detail** → **Lab expected vs actual**.

6. Logout → `admin@demo-insurer.demo` / same password → Lab same scenario → **different** L3/L4 actions (insurer plan).

7. **Reset** then re-seed:
   ```bash
   curl -s -X POST "http://localhost:8081/internal/v2/demo/reset" \
     -H "X-ML-Service-Token: $ML_SERVICE_TOKEN"
   curl -s -X POST "http://localhost:8081/internal/v2/demo/seed?tenant=all" \
     -H "X-ML-Service-Token: $ML_SERVICE_TOKEN"
   ```
   Only `is_demo` tenants are wiped; login works again on clean data.
